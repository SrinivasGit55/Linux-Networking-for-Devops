# Linux Networking for DevOps

This repository contains beginner-friendly networking notes and learning files for DevOps, Linux networking, and CCNA-style fundamentals.

## Files

- [Network-Basics.md](./Network-Basics.md)
- [IP-Addressing.md](./IP-Addressing.md)
- [notes.md](./notes.md)
- [README.md](./README.md)

## Repository Purpose

This repository focuses on practical networking concepts useful for DevOps, system administration, cloud operations, and networking interviews.

## Topics Covered

- Network fundamentals
- OSI and TCP/IP models
- IP addressing basics
- IPv4 concepts and addressing flow
- Subnetting for Class C IPv4 networks
- Network IDs, broadcast IDs, and valid host ranges
- VLSM and efficient address planning
- Gateway and routing concepts
- Practical network troubleshooting

## Recommended Study Order

1. Start with the network basics file.
2. Move to IP addressing concepts.
3. Review the CCNA Day 3 IPv4 addressing lesson.
4. Study Class C subnetting and CIDR logic.
5. Practice network validation and troubleshooting scenarios.
6. Continue with additional networking topics as needed.
