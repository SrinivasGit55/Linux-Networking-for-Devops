## Repository Purpose

This repository is designed for practical learning in:
- Linux networking
- IPv4 addressing
- CIDR and subnetting
- CCNA-style networking fundamentals
- DevOps network design and troubleshooting

## Key Topics Covered

- Network fundamentals
- OSI and TCP/IP model
- IP addressing basics
- Private vs public IPs
- NAT
- IPv4 addressing flow
- CIDR and classless addressing
- Class C subnetting
- Borrowing bits from host portion
- Magic table for Class C
- Network ID, broadcast ID, valid hosts
- VLSM and efficient subnet allocation
- AWS VPC and cloud subnetting examples
- Docker and Kubernetes networking basics
- Firewall and security CIDR examples
- Practical network troubleshooting

## Recommended Learning Order

1. Start with Network-Basics.md
2. Study IP-Addressing.md
3. Understand CIDR and classless addressing
4. Learn Class C subnetting with the magic table
5. Practice subnet calculations using ipcalc
6. Study VLSM and efficient IP planning
7. Apply subnetting in DevOps and cloud networking scenarios
